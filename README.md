# Student Attendance Management System

A web-based Student Attendance Management System developed using PHP and MySQL.

## Features

- Admin Login
- Add New Student
- View Students
- Search Students
- Edit Student Details
- Delete Student
- Mark Attendance
- Prevent Duplicate Attendance
- Attendance Report
- Date-wise Attendance
- Admin Logout

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- phpMyAdmin
- Visual Studio Code

## Project Modules

### 1. Admin Login
Secure login page for the administrator.

### 2. Student Management
Admin can add, view, search, edit and delete student records.

### 3. Attendance Management
Admin can mark students as Present or Absent for a selected date.

### 4. Attendance Report
Admin can view attendance records and filter them by date.

## Database

The project uses MySQL database named `attendance_db`.

Main tables:

- `students`
- `attendance`
- `admin`

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into:
   `C:\xampp\htdocs\`
4. Create the `attendance_db` database in phpMyAdmin.
5. Import/create the required tables.
6. Open the project in a browser:

   `http://localhost/attendance_system`
